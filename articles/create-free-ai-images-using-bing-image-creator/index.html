How To Create Free AI Images Using Bing Image Creator

By Prompt Library • 17 May 2024

If you are an AI-generated photo lover and love to create unique images using AI image-generation tools, Bing Image Creator is a free AI image-generation tool from which you can generate the best high-quality images.

But if you don’t know how to create images from Bing Image Creator, this detailed step-by-step guide will help you.

Button Timer

Before going to create images, make sure that you have a Microsoft Account. To use Bing Image Creator, it is necessary to have a Microsoft Account. If you don’t have that, first of all, go and create a Microsoft Account.

Steps To Create Images Using Bing AI Image Creator

If you have created a Microsoft account, so you are ready to create images from the Bing image generator.

Below are the steps that you have to follow to create images:

1. Go to the Bing Image Creator website.

2. Tap on the “Join & Create” button.

3. Now, log in with your Microsoft Account.

4. After that, write a prompt in the input box or paste the image prompt.

5. Make changes to the prompt according to your needs.

6. After that, click on the “Create” button.

Wait for some time for processing, and finally, you will get your images.

Download it and save it in your gallery.

If the generated images are not according to your prompt or do not get accurate images, you have to check your prompt and create again.

Bing Image Creator gives 15 points per account. From this, you can create images 15 times a day. After 24 hours, the points will renew again.

Why Is Bing Image Creator Not Working

Like many others, I’ve been frustrated by Bing Image Creator’s quirks. Getting the “You can’t submit any more prompts” message when there are no ongoing creations is a real head-scratcher. Here’s what I’ve found digging into this:

The “Ongoing Creation” Lie:

This message usually means you’ve hit your daily limit for image generation. It’s a kind of cool-down period, lasting a day or so. It’s annoying, but at least it’s temporary.

The “Mysterious Busy System:

Ever gotten the “We can’t create right now” message after waiting for ages? Turns out, Bing Chat might block your prompt for content reasons, even if it seems innocuous.

The dedicated Bing Image Generator page might show a “Prompt Blocked” message instead.

The General “Unreliable Wait Times”:

Waiting hours for an image, only to be met with the same message again? You’re not alone. Bing seems to be struggling with demand, and wait times can be wildly unpredictable.

It’s a gamble, especially during peak hours.

Is it Really About the Content?

There’s some debate here. While blatantly inappropriate prompts will get flagged, some users report getting the “Unsafe image content detected” message for seemingly harmless prompts.

Bing’s filter might be a little overzealous at times.

So, What Can We Do?

  • Be Patient: For the daily limit and unreliable wait times, there’s not much we can do but wait it out.
  • Try Bing Image Generator Directly: If Bing Chat blocks your prompt, head over to the dedicated Bing Image Generator page (https://www.bing.com/create). You might get a clearer error message there.
  • Experiment with Prompts: If you’re getting flagged for “unsafe content,” try rephrasing your prompt.
  • Report Issues: Let Microsoft know! Use their feedback channels to report these problems. The more they hear about it, the sooner they might address them.

Hopefully, Bing will iron out these kinks soon. In the meantime, let’s keep sharing our experiences and hopefully find some workarounds together.

And who knows, maybe Bing will listen to our feedback and make the Image Creator a more reliable tool for everyone.

How To Create Better Prompts For Bing Image Creator?

When using the Bing Image Creator, the key is to write your prompts carefully. This will help you get images that match what you want.

Start Your Prompt Strong

  • Begin your prompt with clear, descriptive words that focus on the type of image you’d like to generate.
  • Avoid vague phrases – instead, use at least 6 specific, detailed keywords.

Include Lots of Details

  • Describe the subject, setting, style, and other important elements you want in the image.
  • For example, say “a fluffy golden retriever puppy playing fetch in a lush green park on a sunny day” instead of just “a dog.“
  • Every word you include should contribute to the image you have in mind. Skip the filler words.

Get Creative and Imaginative

  • Feel free to use more unique, outside-the-box wording in your prompts.
  • You could try something like “a robot florist delivering a bouquet of chrome roses in a neon-lit cyberpunk city.”

Add Some Structure

  • Include instructions for the type of image, such as “create an oil painting of” or “generate a digital illustration of.”
  • Perfect image prompts helps guide the AI system toward the right style and medium.

By using specific descriptions, creative language, and clear directions, you can prompt the Bing Image Creator to make unique, high-quality images that match your vision.
